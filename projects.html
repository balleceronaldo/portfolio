Worship Song App

Stack: Flask, SQLAlchemy, Flask-Migrate, SQLite (PostgreSQL-ready via DATABASE_URL)

Core Features: Song library (title, author, key, tempo, themes, lead sheet), chord transposition (including slash/extended chords), worship-set builder, and TXT/PDF export with preview page.

Access Control: Session-based login with role separation: worship_leader (full write/import/export) and musician (read-only). First-time setup route for initial leader account at /auth/setup.

Data Import/Export: JSON/CSV export and import with duplicate policies (replace/skip/rename/error) plus validate_only=true dry-run mode.

Engineering Quality: Automated tests for chord transposition behavior and PDF pagination/song-boundary rules.

AI Use: AI-assisted coding support was used to accelerate implementation, refactoring, and test coverage hardening.

Hazardous Waste Management System

Stack: Flask with secure auth/session flow, CSRF protection, rate limiting, SMTP reset support, and hashed credentials.

Operational Model: Designed for one organization acting as waste collector/generator, internal storage/TSD operator, and outbound shipper to destination TSD through transporters.

Core Features: Source/transporter/TSD master data, waste master-detail logs with auto-summed total weight, manifest and chain-of-custody tracking, compliance contact records (PCO + managing head), and periodic reports (monthly/quarterly/semiannual/yearly).

Exports: CSV, XLSX, and PDF reporting output for compliance documentation workflows.

Security and Runtime: Forced password change for default admin, login/reset rate limits, forgot-password flow with local logging fallback when SMTP is unavailable.

Deployment: Local release zip with run_hazwaste.bat, plus production paths via wsgi.py, Gunicorn/Procfile, Docker, and /healthz.

AI Use: AI-assisted development was used to speed up workflow design, report logic iterations, and deployment packaging consistency.

Local Information Management App (FastAPI)

Stack: FastAPI + SQLite with template-driven UI and custom theming.

Core Features: Entry management (title, content, type, location, category), category/type lifecycle operations (rename/delete/reassign), role-based access (viewer, editor, admin), admin user tools, branding controls, and export features (CSV/JSON/PDF).

Search: Relevance-ranked matching with title priority, multi-word any-word matching, and advanced query syntax support for quoted phrases, OR, and exclude operators (-term / -"phrase").

Analytics: Integrated stats page with chart/table summaries for quick operational review.

Project Structure: Backend modules (main.py, models.py, database.py), templates under app/templates, stylesheet style.css, and seed loader sample_loader.py.

AI Use: AI-assisted coding contributed to feature planning, query behavior implementation, and UI/data-flow refinement.
